# Radhe Krishna Traders - Premium Spices & Chilli Website

A premium showcase website featuring spices, raw red chillies (graded L1, L2, L3), and signature blends.

## Tech Stack
- HTML5 (Semantic elements)
- CSS3 (Variables, Custom Grid/Flexbox, Backdrop Filter Glassmorphism)
- Vanilla Javascript (Interactive Ratio normalizer, Heat level estimator, Form simulator)

## Features
- **Visuals**: Earthy dark mode with glowing accents and customized responsive vector logos.
- **Grades Grid**: Comparison of L1 (Supreme), L2 (Premium), and L3 (Standard) raw chillies.
- **Spice Catalog**: Live active stocks and blurred "Coming Soon" sections.
- **Custom Spiciness Calculator**: Ratios normalizer sliders that automatically adjust to sum up to exactly 100% and calculate predicted heat level (SHU).
- **Form Submission**: Form verification and success pop-up.
